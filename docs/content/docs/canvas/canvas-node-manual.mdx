# Canvas Node Guide

## Text nodes

Text nodes store prompts, drafts, descriptions, and AI-generated text. Double-click the content or select **Edit Text** in the toolbar to edit it. The toolbar also controls text size.

Select **Edit** to open the prompt panel below the node:

- An empty node generates text into itself.
- Editing an existing node creates a connected result node to the right, preserving the original.
- Use `@` to reference connected images, text, video, or audio. Image references appear as thumbnails and are numbered automatically when sent to the model.
- The model selection applies only to the current node. Fetch or enter model names in global Settings first.

To generate an image from text, prepare the prompt and select **Generate Image**. Infinite Canvas creates and connects a generation configuration node, starts generation, and lets you adjust the model, resolution (`1k` / `2k` / `4k` / auto), aspect ratio, and output count before retrying.

## Image nodes

- Generating from an empty image node writes the first result into that node.
- A single result replaces the current empty node; multiple results use it as the primary node and add result nodes to the right.
- A populated image node is reused as a reference image.
- Generated nodes record the prompt, generation type, model, size, quality, count, and references in `metadata`.
- A retry stops with a clear warning if required references can no longer be restored.

## Video nodes

Create a video node from the toolbar or upload a local video. Video nodes use the native player. An empty video node can generate into itself, while generation started from text, images, or configuration nodes creates a connected video node. Generation-config video mode reads upstream text as the prompt, images as reference images, videos as reference videos, and audio as reference audio. Built-in OpenAI and Gemini requests use the same fields as the insertable call-script templates. Custom video request scripts can read those files from the `videos` and `audios` variables.

Video settings use `480p` / `720p` / `1080p` with `1:1`, `3:4`, `4:3`, `16:9`, `9:16`, `21:9`, or auto, and compute width and height from that pair. Duration is a 4–30 second slider. They also include first-and-last-frame mode and general-reference mode. With first-and-last-frame mode, one image is sent as the first frame and two images as first and last frames. More than two images are sent as general references even if first-and-last-frame mode is selected. Built-in requests and request scripts both use the resolved `frames` or `reference` mode.

The OpenAI-compatible flow uses `POST /v1/videos`, `GET /v1/videos/{id}`, and `GET /v1/videos/{id}/content`, sending `first_frame` / `last_frame` or `image[]` plus optional `video[]` / `audio[]`. Gemini-format channels use `models/{model}:predictLongRunning` and poll the operation, sending `image` / `lastFrame` or `referenceImages`. Set the channel Base URL before `/v1`; for example, use `https://metaso.cn/api/openai` for Metaso MiniMax-H3 and the app appends `/v1/videos`. Entering a full native endpoint such as `/video_generation` in Base URL produces the wrong request URL and a 404. Metaso's OpenAI-compatible endpoint currently accepts only `1280x720` (16:9 768P), `720x1280` (9:16 768P), `1792x1024` (16:9 2K), and `1024x1792` (9:16 2K); selecting 720p with 16:9 or 9:16 in the app produces the first two sizes. Other ratios and 480p/1080p return `Unsupported value for 'size'`. That endpoint also supports only a single image plus a prompt, not multiple images, reference videos, or reference audio. For multiple images, reference videos, or reference audio, insert the **MiniMax native** template in the video model's **Request script** and set the channel Base URL to the native API root (for Metaso, `https://metaso.cn/api/minimax/v2`). The script calls `POST {baseUrl}/video_generation` and polls `GET {baseUrl}/query/video_generation/{task_id}`, sending `first_frame` / `last_frame` / `reference_image` / `reference_video` / `reference_audio` as appropriate. MiniMax-H3 maps 720p to `768P` and 1080p to `2K`, and clamps duration to 4–30 seconds. Reference media is sent as data URLs; upload it to a public URL first if the channel only accepts public URLs. Videos returned by Metaso's OpenAI-compatible endpoint currently have no audio track; use the MiniMax native script with the native Base URL when you need synchronized audio. After a remote task is created, its ID is stored on the video node so a page refresh can keep polling, or you can click **Get task status**. Polling stops when the video is ready, the task fails, or the status request errors.

## Group nodes

Group nodes collect several nodes so you can move them together and reference their contents in one connection.

- After box-selecting or Shift/Ctrl/Cmd-clicking multiple nodes, a rounded dashed bound wraps the selection and **Group** appears above it.
- Click **Group** or press `Ctrl / Cmd` + `G` to wrap the selection in a group node without moving the contents.
- With a group selected, use **Ungroup** in the toolbar or context menu, or press `Ctrl / Cmd` + `Shift` + `G`.
- You can also create an empty group from the toolbar and drag nodes into it; dragging a node out removes it from the group.
- Connecting a group to a generation node includes every populated image, video, audio, text, and reference-capable extension node inside it.

## Recommended workflow

1. Create a text node with the initial idea.
2. Ask AI to refine the prompt in the panel below it.
3. Compare the connected rewritten node with the original.
4. Select **Generate Image** on the chosen text node.
5. Adjust parameters or regenerate from the generated configuration node.
